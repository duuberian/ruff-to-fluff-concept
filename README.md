# Ruff to Fluff — independent website concept
Concept by Daniel for Melanie's grooming parlour in Lake. Not official or endorsed. Buildless HTML/CSS/JS. No customer data storage or network submission; fictional details only. No live services, pricing, availability, testimonials or notification delivery claimed.

Sources reviewed 21 November 2026:
- Melanie's own introduction, published 14 October 2024: https://iwobserver.co.uk/new-dog-grooming-parlour-ruff-to-fluff-opens-in-lake/
- Address cross-check: https://www.fidophotos.uk/useful-links/isle-of-wight-dog-groomers/
- Illustrative stock photograph: https://images.unsplash.com/photo-1552053831-71594a27632d (not a client photo).

Services in the preview are explicitly illustrative enquiry options, not a verified service menu. No historical loyalty offer or assumed opening hours reproduced. Owner approval and updated information required before live use. Email alerts/reminders are proposals. Existing form services or the business's chosen booking platform should be evaluated before adding a custom backend; service costs require agreement.

Hosted on GitHub Pages: https://duuberian.github.io/ruff-to-fluff-concept/

Serve locally with `python -m http.server 8766`.

The main branch root is the GitHub Pages publishing source.
